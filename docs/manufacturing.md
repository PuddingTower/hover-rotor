# 制造接口与工艺指南（hover-rotor）

本文件说明**优化结果如何进入车间**：输出文件的语义、各工艺路线的取舍、以及装机前必须做的校核。
气动侧的推导见 `docs/theory.md`。

---

## 1 一次完整交付产出什么

```
results/
├── sec01_contour.dxf … sec10_contour.dxf     # R2010，单一闭合 LWPOLYLINE，200 顶点，mm
├── sec01_contour.dat … sec10_contour.dat     # Selig 格式（上表面尾缘→前缘，下表面前缘→尾缘）
├── sec01.csv … sec10.csv                     # 归一化 + 弦向 mm + 空间 mm + 扭角 + 气动工作点
├── rotor_blade_solid.step                    # AP214 实体（build123d / OpenCASCADE）
├── rotor_blade_solid.stl                     # 水密流形网格，切片直接可用
├── manufacturing_manifest.csv                # 十截面总表（几何 + 气动 + 结构力学量）
├── rotor_report.json                         # 全配置 + 种子 + 收敛历史，可反序列化复现
├── manufacturing_report.md                   # 人读报表
├── rotor_summary.png                         # 四联气动图版（≥300 DPI）
└── rotor_interactive_3d.html                 # 离线三维交互（plotly.js 内联）
```

坐标系与单位约定（**这是车间最容易踩坑的地方**）：

| 文件 | 单位 | 坐标框 | 是否含扭转 |
| :-- | :-- | :-- | :-- |
| DXF / DAT | mm | 该截面的**弦向框**：x 沿弦、原点在前缘 | 否（下料件无方位） |
| CSV `x_mm/y_mm` | mm | 同上；另给 `x_space/y_space` 叶片坐标 | 两者都给 |
| STEP / STL | mm | 叶片坐标：z = 径向站位，xy 平面内已按安装角旋转 | 是 |
| manifest | mm / deg | 结构量 `area/x_cg/y_cg/i_xx/j_torsion` 一律 **mm 系** | — |

线切割/激光切割只关心轮廓形状，所以 DXF 用未旋转的弦向框；放样成三维实体才需要方位，
所以 STEP 用旋转后的叶片框。两者不是同一组数字，不要互相覆盖。

## 2 尾缘厚度：为什么它是"第一校核项"

钝尾缘的**绝对厚度 $t_{te}$ 全展恒定**，是工艺约束也是强度前提：

- 相对厚度 $\Delta\bar z_{te}=t_{te}/c(r)$ 随弦长变化，所以叶尖（弦最小）处相对钝度最大。
  设计输入校验里 $t_{te}/c_{tip}\le 5\%$ 是硬限（`RotorInputs`），超出即拒绝——
  再钝下去气动代价（基底阻力 ∝ $t_{te}/c$）与放样畸变都不划算。
- 参数化保证每个截面首末两点（尾缘上下角）的间距**严格等于** $t_{te}$，
  所以"10 截面尾缘厚度一致性"不是加工精度问题而是数据正确性问题。
  验收方式：`manufacturing_manifest.csv` 的 `te_thickness` 列极差应 < 0.001 mm（实际为 0）。
- 车间校核：DXF 回读时断言 LWPOLYLINE `closed=True`、200 顶点、首末两点 x 相同（垂直封闭段）。
  这三条在 `tests/test_cad_export.py` 里已经是自动化断言。

**$t_{te}$ 怎么选**：以 §2.4 收益表为据。

| 目标 | 建议 $t_{te}/c$ | 说明 |
| :-- | :-- | :-- |
| 追求 FM、载荷谱温和 | 0.5%~1% | 良率改善明显，$c_d$ 代价小 |
| 复材一体模压、需脱模良率 | 1.5%~3% | 抗弯截面模量翻倍，适合 CNC 铣削一体成型 |
| 叶根承载过渡段、大载荷 | 5%~10% | 抗疲劳最佳，但 $c_d$ 增 40%~90%，需重新权衡 FM |

给绝对厚度而非相对厚度是有意为之：车间只有绝对尺寸概念，且一片桨叶上 $t_{te}$ 恒定
才能用同一把刀具/同一副模具完成全展。

## 3 工艺路线选择

### 3.1 慢走丝线切割（金属模、钛/铝桨毂试验件）
用 DXF。要点：
- 单一闭合多段线 → 直接生成刀轨，无断点补偿；
- 尾缘垂直封闭段是**唯一**直线段，切割方向在此处反转，需置零抬刀或改用引入线；
- 200 点/截面的点距在前缘最密（余弦加密），满足 0.01 mm 级轮廓公差需要。

### 3.2 CNC 五轴铣削（铝模 / 复材共固化）
用 STEP（AP214）。要点：
- `loft(ruled=False)` 走 B 样条蒙皮，刀具路径连续，不需要逐截面拼接；
- 实体已通过 `BRepCheck_Analyzer` 有效性校验（无非流形边、无自交），
  可直接进 CAM；若下游 CAM 报几何错误，先确认它读的是 STEP 而不是把 STL 当实体。

### 3.3 FDM / SLA / SLS 3D 打印（样机、风洞模型）
用 STL。要点：
- 网格已验水密流形（每条边被两片三角形反向共享、Euler 示性数 $\chi=2$、体积与实体一致 ±2%），
  切片软件不会再报 non-manifold；
- 打印方向建议展向水平（z 轴竖直会让尾缘平面成为悬立面）；
- 钝尾缘是**为打印而生的特征**：尖尾缘在 FDM 下几乎必裂，$t_{te}\ge1.5\%c$ 时
  尾缘可自成承载壁，无需支撑。

### 3.4 复材铺层（玻纤/碳纤真空导入）
用 manifest 的结构列 + DAT。要点：
- 用 `i_xx`（抗弯惯性矩）与 `j_torsion`（扭转惯性矩）做配平：铺层设计的目标是把
  刚度轴放在形心轴附近以解耦弯扭，`x_cg/y_cg` 给出形心偏移；
- 尾缘是复材最常见的破损位置：纤维在尖尾缘富集不良、脱模即崩。钝尾缘把该处
  壁厚从 ~0 提到 $t_{te}$，是良率的主要来源；
- 导入流动方向应与 DAT 点序一致（上表面自尾缘到前缘），避免双侧同时充模产生夹气。

## 4 强度与刚度的最低限度校核

`manufacturing_manifest.csv` 每行给出：

$$
A=\oint\mathrm{d}A,\qquad
(x_{cg},y_{cg})=\frac1A\oint(x,y)\,\mathrm{d}A,\qquad
I_{xx}=\oint y^2\,\mathrm{d}A - A\,y_{cg}^2
$$

（多边形面积分 + 平行轴定理；对 NACA0012 已用解析解校核到 <1%。）

$J$（扭转惯性矩）按**单室薄壁 Bredt 公式** $J=4A^2/\oint \mathrm{d}s/t$ 计算，
壁厚取同一 $\psi$ 处上下表面的垂直间距，尾缘平面壁以 $t=t_{te}$ 计入。
注意其收敛仅 $O(h^{1/2})$（前缘处 $t\sim\sqrt{\psi}$），200 点与 2000 点差约 2%，
所以测试用 5% 容差，实际校核也应把它当**同数量级估计**而非精确值。

必查三件事：
1. **挥舞刚度**：$EI_{xx}$ 沿展向的分布是否避开桨叶一阶挥舞固有频率（通常要求 ≥1.3 倍裕度）。
2. **扭转刚度**：$GJ$ 决定气动弹性发散速度；钝尾缘把 $J$ 抬高（§2.4 表列根部 +25%~+120%），
   这是它相对尖尾缘最实在的结构收益。
3. **尾缘局部承压**：$t_{te}$ 处的胶接/共固化边缘是裂纹源，边缘半径不要小于 2 倍铺层厚度。

气动最优构型可能把工作迎角推到 $c_{l,\max}$ 附近（本实现的基准工况就如此），
装机前请对照 `secNN.csv` 的 `alpha_deg` 与翼型实测失速迎角留出裕度。

## 5 复现与验收

任何一次生成都应可复现：

```bash
hover-rotor-opt --thrust 80 --radius 0.75 --te-thickness 0.0025 --seed 2026 --output-dir ./results
```

- `rotor_report.json` 内含全部输入、边界、种子与收敛历史；
  `RotorResult.from_dict(json.load(...))` 必须还原出等价对象（测试已断言）。
- 固定种子两次运行应得到逐位一致的构型；若不一致，说明引入了非确定性（并行归约顺序、
  缓存未命中等），属于缺陷。
- 验收红线达成情况见 `docs/theory.md` §4 与 README 的验收表：
  Caradonna–Tung 的 ≤5% 与 FM≥0.68 两条**当前未达成**，原因与证据都已写明，
  不要在生产决策中把它们当作已通过。
